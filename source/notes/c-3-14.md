# Organic synthesis
- Plan routes using the reaction map: alkane → halogenoalkane → alcohol → aldehyde or ketone → carboxylic acid → ester, amide, etc.
- To add a carbon: a halogenoalkane + KCN gives a nitrile. Then reduce it (amine), or use an aldehyde + HCN to make a hydroxynitrile.
- Key reagents: NaOH(aq) (substitution) vs KOH/ethanol (elimination); acidified K₂Cr₂O₇ (oxidation); NaBH₄ (reduction); concentrated H₂SO₄ (esterification, dehydration).
# Practical techniques
- Reflux, distillation, separating funnel (remove the aqueous layer), drying with anhydrous MgSO₄, recrystallisation (minimum hot solvent, cool, filter under reduced pressure), melting point to test purity.
- Overall yield of a multistep route = the product of the individual yields.
# Green chemistry
- Fewer steps, high atom economy, safer solvents, and catalysts.
# Exam tips
> For every step, give the **reagent, conditions and type of reaction**, and name the intermediate.
