# Alkanes and fuels
- Saturated hydrocarbons. Fractional distillation of crude oil: there is a temperature gradient in the column; smaller molecules condense higher up.
- **Thermal cracking:** high $T$ and pressure, making many alkenes. **Catalytic cracking:** zeolite, about 450 °C, slight pressure, making aromatics and branched alkanes.
# Combustion and pollution
- Complete: CO₂ + H₂O. Incomplete: CO (toxic) and C (soot).
- NOₓ forms from N₂ + O₂ at high engine temperatures. SO₂ forms from sulfur impurities and causes acid rain; it is removed with CaO.
- Catalytic converter (Pt/Rh): 2CO + 2NO → 2CO₂ + N₂.
# Free-radical substitution
- Initiation: Cl₂ → 2Cl• (UV).
- Propagation: CH₄ + Cl• → •CH₃ + HCl, then •CH₃ + Cl₂ → CH₃Cl + Cl•.
- Termination: two radicals combine, e.g. •CH₃ + •CH₃ → C₂H₆.
- Ozone depletion: Cl• + O₃ → ClO• + O₂, then ClO• + O₃ → 2O₂ + Cl•. Cl• is regenerated, so it acts as a catalyst.
# Exam tips
> Further substitution gives a mixture of products, so free-radical substitution is a poor way to make one specific product.
