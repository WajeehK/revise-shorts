# NMR spectroscopy
- TMS, Si(CH₃)₄, is the standard (δ = 0). It is inert, volatile and gives a single strong peak. Solvents with no ¹H, such as CDCl₃, are used.
- **¹³C NMR:** the number of peaks equals the number of carbon environments. Chemical shift identifies the type of carbon (C=O is about 160–220 ppm).
- **¹H NMR:** the number of peaks equals the number of H environments. The integration ratio gives the relative number of H in each environment.
- **Splitting (n + 1 rule):** a peak is split by n H atoms on **adjacent** carbons. A singlet has 0 neighbours, a doublet 1, a triplet 2, a quartet 3.
- O–H and N–H usually appear as singlets.

# Worked example
Ethyl ethanoate CH₃COOCH₂CH₃ has 3 peaks: a singlet (3H, CH₃CO), a quartet (2H, OCH₂) and a triplet (3H, CH₂CH₃).
# Exam tips
> A quartet + triplet in a 2 : 3 ratio usually means an ethyl group.
