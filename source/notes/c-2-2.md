# Group 2 trends (down the group)
- Atomic radius increases, first IE decreases, and reactivity increases.
- Melting point generally decreases (larger ions, weaker metallic bonding).
- Hydroxide solubility **increases** (Mg(OH)₂ is sparingly soluble). Sulfate solubility **decreases** (BaSO₄ is insoluble).
# Reactions
- With water: M + 2H₂O → M(OH)₂ + H₂. Mg reacts very slowly with cold water but burns in steam: Mg + H₂O → MgO + H₂.
- Test for sulfate: acidified BaCl₂ gives a white BaSO₄ precipitate. HCl is added first to remove carbonate.
# Uses
- Mg(OH)₂: antacid. Ca(OH)₂: neutralising acidic soil. BaSO₄: barium meal (it's insoluble, so not toxic).
- CaO or CaCO₃: removing SO₂ from flue gases. Mg: extracting Ti from TiCl₄ (TiCl₄ + 2Mg → Ti + 2MgCl₂).
# Exam tips
> Barium compounds are toxic, but BaSO₄ is safe because it is insoluble. Say that explicitly.
