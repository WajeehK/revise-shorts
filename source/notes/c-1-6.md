# Dynamic equilibrium
- Forward and reverse rates are equal, and concentrations stay constant (closed system).
- **Le Chatelier:** if a condition changes, the position of equilibrium shifts to oppose the change.
- Increasing pressure shifts to the side with fewer gas moles. Increasing $T$ shifts in the endothermic direction. A catalyst doesn't change the position, only how fast equilibrium is reached.

# Kc
For $a\text{A}+b\text{B}\rightleftharpoons c\text{C}+d\text{D}$:
$$K_c=\frac{[\text{C}]^c[\text{D}]^d}{[\text{A}]^a[\text{B}]^b}$$
- Only **temperature** changes $K_c$. Units: cancel the concentration terms.
- Use an ICE table (initial, change, equilibrium). Divide moles by volume to get concentrations.
# Industrial compromises
- Haber process: 450 °C (rate vs yield), 200 atm (yield vs cost and safety), iron catalyst.
# Worked example
H₂ + I₂ ⇌ 2HI. Start with 1.0 mol of each in 1.0 dm³; 0.80 mol HI at equilibrium, so 0.60 mol each of H₂ and I₂ remain. $K_c=\frac{0.80^2}{0.60^2}=1.78$ (no units).
# Exam tips
> If the forward reaction is exothermic, increasing $T$ **decreases** $K_c$.
