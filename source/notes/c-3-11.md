# Amines
- Primary RNH₂, secondary R₂NH, tertiary R₃N. Quaternary ammonium salts R₄N⁺ X⁻ are cationic surfactants (fabric softeners and hair conditioners).
- They are bases: the lone pair on N accepts H⁺. Strength: primary aliphatic > NH₃ > phenylamine. Alkyl groups push electrons on to N; the benzene ring delocalises N's lone pair.
# Preparation
- From halogenoalkanes + excess NH₃. Further substitution gives a mixture of products.
- From nitriles: reduce with LiAlH₄ or H₂/Ni. This gives only the primary amine.
- Aromatic: nitrobenzene + Sn/concentrated HCl, then NaOH, gives phenylamine.
# Reactions
- As nucleophiles: with halogenoalkanes (substitution) and with acyl chlorides (addition–elimination, forming amides).
# Worked example
Rank in order of base strength: ethylamine > ammonia > phenylamine.
Ethylamine: the ethyl group is electron-releasing (positive inductive effect), so the N lone pair is more available to accept H⁺. Phenylamine: the N lone pair is delocalised into the benzene ring, so it is less available.
# More reactions
- Amine + acid → salt, e.g. CH₃NH₂ + HCl → CH₃NH₃⁺Cl⁻.
- Amine + acyl chloride → N-substituted amide + HCl (nucleophilic addition–elimination), e.g. CH₃COCl + CH₃NH₂ → CH₃CONHCH₃ + HCl.
# Common mistakes
- Explaining base strength with "electronegativity" instead of the availability of the lone pair on N.
- Forgetting that excess ammonia is needed to favour the primary amine.
# Exam tips
> Explain base strength by the **availability of the lone pair** on N.
